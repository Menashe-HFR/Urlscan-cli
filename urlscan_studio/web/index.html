    MORE THAN A PRETTY DASHBOARD

    Small surface.
    Thoughtful engineering.

    A Python backend built around the awkward parts of real API work.

    CLI / Dashboard→FastAPI→SQLite queue→Async workers→urlscan.io
    01

    Durable by design

    Jobs, results and events survive process restarts. Submitted scan IDs are stored before polling so interrupted work can resume.

    02

    A little restraint

    Bounded concurrency, HTTP timeouts, exponential backoff and provider quota waits. A failed scan stays unknown.

    03

    Useful interfaces

    Validated batches, idempotency keys, cancellation, failed-item retries, scoped cache, CSV and JSON exports.

    04

    Honest demo mode

    This static demo simulates the workflow with fictional data. Run the Python service for real API jobs, persistence, caching and OpenAPI docs.
